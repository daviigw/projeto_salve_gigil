🐶 Salve Gigil

Um jogo de aventura, exploração e desafios desenvolvido em Python.

📖 Sobre o projeto

Salve Gigil é um jogo desenvolvido em Python utilizando a biblioteca Pygame. O projeto tem como proposta unir programação, criatividade e entretenimento por meio de uma aventura ambientada em um laboratório cheio de obstáculos, mecanismos e desafios.

O jogador assume o controle de um estudante que precisa explorar as instalações, superar dificuldades e encontrar uma maneira de escapar. Durante essa jornada, ele descobre que a mascote da escola, Gigil, também foi capturada e precisa ser resgatada.

A partir dessa descoberta, a missão passa a ser salvar a mascote e garantir que ambos consigam escapar do laboratório.

🎮 História do jogo

A aventura começa quando um estudante da ETE acorda em um laboratório desconhecido, após ter sido sequestrado.

Ao explorar o ambiente, ele encontra pistas sobre o local e descobre que sua cadela, Gigil, também está presa nas instalações.

Determinado a escapar e resgatá-la, o protagonista precisa percorrer diferentes setores do laboratório, superar sistemas de segurança, encontrar recursos e solucionar desafios.

Ao longo da jornada, Gigil deixa de ser apenas alguém que precisa ser resgatada e passa a ajudar o jogador em determinadas situações.

🎯 Objetivos

O principal objetivo é conseguir escapar do laboratório junto com Gigil.

Para isso, o jogador precisa:

- Explorar os diferentes ambientes do laboratório.
- Encontrar e coletar itens importantes.
- Desbloquear portas e mecanismos.
- Resolver desafios envolvendo terminais e painéis.
- Evitar obstáculos e sistemas de segurança.
- Resgatar Gigil e utilizar sua ajuda durante a aventura.
- Completar as missões necessárias para alcançar a saída.

⚙️ Mecânicas e funcionalidades

O jogo apresenta diferentes sistemas de interação e movimentação:

Exploração: permite percorrer os ambientes e descobrir caminhos e objetivos.

Coleta de itens: determinados objetos são necessários para liberar acessos e avançar nas missões.

Resgate da Gigil: o jogador precisa encontrar e libertar sua mascote.

Sistema de acompanhamento: após o resgate, Gigil pode acompanhar o protagonista.

Interação com a mascote: algumas situações exigem que Gigil alcance locais específicos para ajudar na progressão.

Terminais e painéis: mecanismos utilizados para ativar sistemas e liberar determinados caminhos.

Obstáculos e lasers: sistemas de segurança que exigem atenção e estratégia para serem superados.

Progressão por fases: cada etapa apresenta novos ambientes, objetivos e desafios.

🧪 Tecnologias utilizadas

O desenvolvimento do projeto utiliza:

- Python: linguagem de programação responsável pela lógica e funcionamento do jogo.
- Pygame: biblioteca utilizada para criar os elementos gráficos, movimentação, colisões, animações e interações.
- Git: ferramenta de versionamento utilizada para registrar alterações no código.
- GitHub: plataforma utilizada para armazenar e organizar o repositório do projeto.

💻 Como executar o jogo

Requisitos

- Python instalado no computador.
- Biblioteca Pygame.
- Arquivos e recursos do projeto disponíveis na pasta correta.

Instalação

Instale a biblioteca Pygame pelo terminal:

python -m pip install pygame

Execução

Abra o terminal na pasta principal do projeto e execute:

python main.py

Em alguns sistemas, pode ser necessário utilizar:

py 3.13(ou a versão instalada) -m pip install pygame

e

py 3.13(ou a versão utilizada) main.py

para rodar o jogo
