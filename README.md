Salve Gigil 🐶

Sobre o projeto

Salve Gigil é um jogo desenvolvido em Python utilizando a biblioteca Pygame.

No jogo, o jogador precisa explorar um laboratório, superar obstáculos, resolver desafios e coletar itens para conseguir escapar e resgatar a mascote GIGIL, que também está presa no local.

Objetivo

Explorar as fases do laboratório, cumprir as missões, encontrar os recursos necessários e salvar a GIGIL, garantindo que os dois consigam escapar.

Tecnologias utilizadas

- Python
- Pygame

Como executar

1. Instale o Python.
2. Abra o Terminal 
3. Instale a biblioteca Pygame no Terminal com o comando:

python -m pip install pygame

3. Abra a pasta do projeto no Terminal.
4. Execute:

python main.py

Estrutura do projeto

- "main.py" — arquivo principal do jogo.
- "assets/" — imagens, sprites e outros recursos utilizados.
- "README.md" — documentação do projeto.
